# Focus Flow

Extensión para Firefox que ayuda a trabajar por sesiones de concentración y descanso. Incluye un temporizador y una animación hecha con p5.js que muestra cómo pasa el tiempo.

## Funcionalidades

- Sesiones de concentración de 25, 45 o 60 minutos.
- Descansos de 5 minutos.
- Botones para iniciar, pausar, reanudar y reiniciar.
- Contador de sesiones completadas.
- Animación generativa con p5.js.
- Guarda el estado aunque se cierre la ventana de la extensión.

## Instalación

1. Descarga o clona este repositorio.
2. Abre Firefox y escribe `about:debugging#/runtime/this-firefox` en la barra de direcciones.
3. Pulsa **Cargar complemento temporal...** y selecciona el archivo `manifest.json`.
4. Haz clic en el icono de Focus Flow en la barra de herramientas.


## Tecnologías

HTML, CSS, JavaScript y p5.js.
